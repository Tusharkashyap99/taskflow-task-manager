# TaskFlow – Smart Task Manager

TaskFlow is a responsive task management web application built using HTML, CSS, and JavaScript. It helps users organize daily tasks, set priorities, track progress, and manage deadlines through a simple and user-friendly interface.

## 🚀 Live Demo

[Click here to use TaskFlow](https://tusharkashyap99.github.io/taskflow-task-manager/)

## ✨ Features

- **Add Tasks:** Create tasks with a title and optional due date.
- **Priority Management:** Assign Low, Medium, or High priority to tasks.
- **Task Tracking:** Mark tasks as completed or in progress.
- **Search Tasks:** Find tasks by their titles.
- **Filter Tasks:** View all, active, or completed tasks.
- **Sort Tasks:** Organize tasks by creation time, priority, or due date.
- **Progress Dashboard:** View total tasks, active tasks, completed tasks, and completion progress.
- **Local Storage:** Save tasks in the browser so they remain available after refreshing the page.
- **Responsive Design:** Use the application on desktop and mobile screens.

## 🛠️ Technologies Used

- HTML5 – Application structure
- CSS3 – Styling and responsive layout
- JavaScript – Application logic and interactivity
- Browser Local Storage – Client-side data persistence
- GitHub Pages – Website deployment

## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Tusharkashyap99/taskflow-task-manager.git
   ```

2. Open the project folder:

   ```bash
   cd taskflow-task-manager
   ```

3. Open `index.html` in your web browser.

No additional dependencies or installations are required.

## 📌 Limitations

Tasks are stored in the browser's local storage. They are not synchronized across devices, and clearing the browser's site data may remove saved tasks.
